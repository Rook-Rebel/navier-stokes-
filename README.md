# ნავიე-სტოქსის სინგულარობა

ქართულენოვანი ინტერაქტიული 3D ვიზუალიზაცია იმისა, თუ როგორ შეიძლება გლუვმა ნაკადმა სასრულ დროში დაკარგოს სიგლუვე: მბრუნავი მორევი → რადიალური შეკუმშვა → ღერძული გაწელვა → სიჩქარისა და ვორტიციტეტის ზრდა → სინგულარობასთან მიახლოება.

შთაგონებულია 2026 წლის 8 სექტემბერს OpenAI-ის მიერ გამოქვეყნებული კონსტრუქციით ([განცხადება](https://openai.com/index/navier-stokes-solution/), [Lean ფორმალიზაცია](https://github.com/openai/NavierStokesAndEuler)).

> „ეს ვიზუალიზაცია წარმოადგენს მტკიცების მექანიზმის ინტერაქტიულ სასწავლო მოდელს და არა 166-გვერდიანი მათემატიკური მტკიცების სრულ რიცხვით სიმულაციას.“

აპლიკაცია მტკიცებას არც იმეორებს და არც ამოწმებს.

## რა არის შიგნით

- 3D ლაბორატორია ექვსი რეჟიმით: ნაწილაკები, ტრაექტორიები, სიჩქარის ველი, ვორტიციტეტი, ენერგია, შედარება
- დროის ღერძი, პარამეტრების სლაიდერები, ცოცხალი მონაცემები და სინქრონიზებული გრაფიკები
- განტოლების ინტერაქტიული ახსნა, ნაბიჯ-ნაბიჯ გზამკვლევი, შედარებები და წყაროები

## მოდელი

სიჩქარის ველი ([`src/utils/flowField.ts`](src/utils/flowField.ts)) არის სასწავლო, ზუსტად დივერგენციისგან თავისუფალი ღერძულ-სიმეტრიული მოდელი: ორი წრფივი დაძაბვის ველი და Burgers/Lamb–Oseen ტიპის ბრუნვა. ტრაექტორიები ჩაკეტილი ფორმულებით გამოითვლება, ამიტომ ეკრანზე ნაჩვენები ყველა რიცხვი პირდაპირ ამ ფორმულებიდან მოდის.
